# Phase I - In-Memory Python Console Todo Application

A simple command-line todo list application built following Spec-Driven Development (SDD) methodology. This is Phase I of the "Evolution of Todo" project.

## Features

- ✅ Add tasks with title and optional description
- ✅ View all tasks in a formatted table
- ✅ Mark tasks as complete or incomplete
- ✅ Update task title and/or description
- ✅ Delete unwanted tasks
- ⚠️ In-memory storage (tasks are lost when application exits)

## Prerequisites

- **Python 3.13+** installed
- **UV package manager** installed

### Installing UV

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Installation

1. Clone the repository:
```bash
cd /path/to/todoAppr
```

2. Install dependencies:
```bash
uv sync --extra dev
```

This will install:
- `pydantic>=2.0` (data validation)
- `pytest>=8.0` (testing framework)
- `pytest-cov>=4.0` (coverage reporting)

## Usage

### Running the Application

```bash
uv run python src/main.py
```

### Main Menu Options

```
1. Add Task - Create a new task with title and description
2. View All Tasks - Display all tasks in a table format
3. Update Task - Modify existing task title/description
4. Delete Task - Remove a task from the list
5. Mark Task Complete/Incomplete - Toggle completion status
6. Exit - Quit the application (all data will be lost)
```

### Example Workflow

```
1. Select option "1" to add a task
   - Enter title: "Buy groceries"
   - Enter description: "Milk, eggs, bread"

2. Select option "2" to view all tasks
   - See your task displayed with ID, status, title, description

3. Select option "5" to mark task complete
   - Enter the task ID
   - Task status changes to [X]

4. Select option "3" to update a task
   - Enter task ID
   - Update title or description (leave empty to keep current)

5. Select option "4" to delete a task
   - Enter task ID
   - Confirm deletion with 'y'
```

## Technical Details

### Data Model

**Task** entity with:
- `id`: Unique identifier (auto-assigned, sequential)
- `title`: 1-200 characters (required)
- `description`: 0-1000 characters (optional)
- `completed`: Boolean (default: False)

### Validation

- Empty titles are rejected
- Titles > 200 characters are rejected
- Descriptions > 1000 characters are rejected
- Non-numeric or invalid task IDs show clear error messages

### Data Storage

- **In-memory**: Tasks stored in a Python list during the session
- **No persistence**: All tasks are lost when the application exits
- **Sequential IDs**: Task IDs auto-increment starting from 1
- **No ID reuse**: Deleted task IDs are never reused within a session

## Limitations (Phase I)

- No data persistence (tasks lost on exit)
- Single-user application
- No search, filter, or sort capabilities
- No due dates, priorities, or tags
- Text-based interface only (no colors or formatting)
