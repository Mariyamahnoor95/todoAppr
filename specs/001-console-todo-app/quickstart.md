### Step 3: Configure UV Project

**File**: `pyproject.toml`

**Expected Content**:
```toml
[project]
name = "todo-console"
version = "0.1.0"
description = "Phase I - In-Memory Python Console Todo Application"
requires-python = ">=3.13"
dependencies = [
    "pydantic>=2.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=8.0",
    "pytest-cov>=4.0",
]

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[tool.pytest.ini_options]
testpaths = ["tests"]
python_files = "test_*.py"
python_functions = "test_*"
addopts = "--cov=src --cov-report=term-missing --cov-report=html"

[tool.coverage.run]
source = ["src"]
omit = ["tests/*"]

[tool.coverage.report]
fail_under = 90
```

**Install Dependencies**:
```bash
uv sync
```

### Step 6: Manual Testing

**Test Scenarios** (from spec acceptance criteria):

#### Test 1: Add and View Tasks (User Story 1 - P1)
```
1. Select "1" (Add Task)
2. Enter title: "Buy groceries"
3. Enter description: "Milk, eggs, bread"
4. Verify success message shows ID, title, description, status
5. Select "2" (View All Tasks)
6. Verify task appears in list
```

#### Test 2: Mark Complete (User Story 2 - P2)
```
1. Add a task (if not already present)
2. Note the task ID
3. Select "5" (Mark Complete/Incomplete)
4. Enter task ID
5. Verify status changes to "Complete" ([X])
6. Repeat steps 3-4
7. Verify status changes back to "Incomplete" ([ ])
```

#### Test 3: Update Task (User Story 3 - P3)
```
1. Add a task with title "Buy grocries" (intentional typo)
2. Select "3" (Update Task)
3. Enter task ID
4. Enter new title: "Buy groceries"
5. Leave description empty (press Enter)
6. Verify only title updated
```

#### Test 4: Delete Task (User Story 4 - P4)
```
1. Add a task
2. Note the task ID
3. Select "4" (Delete Task)
4. Enter task ID
5. Confirm deletion (y)
6. Select "2" (View All Tasks)
7. Verify task no longer appears
```

#### Edge Case Testing
```
- Empty title: Try adding task with empty title → should show error
- Long title: Try adding task with 201 characters → should show error
- Invalid ID: Try updating task ID 999 → should show "Task not found"
- Non-numeric ID: Try entering "abc" as ID → should show format error
```

## Troubleshooting

### Issue: `uv: command not found`

**Solution**:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc  # or ~/.zshrc
```

---

### Issue: `python: No module named pydantic`

**Solution**:
```bash
uv sync  # Ensures all dependencies installed
```

---

### Issue: Tests fail with `ModuleNotFoundError: No module named 'src'`

**Solution**:
Add `src/` to Python path or run tests with:
```bash
PYTHONPATH=. uv run pytest
```

Or configure in `pyproject.toml`:
```toml
[tool.pytest.ini_options]
pythonpath = ["."]
```

---

### Issue: Coverage below 90%

**Solution**:
```bash
# Generate HTML coverage report
uv run pytest --cov=src --cov-report=html

# Open in browser
open htmlcov/index.html

# Identify missing lines and add tests
```
